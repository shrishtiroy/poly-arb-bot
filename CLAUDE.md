# Project rules

## Never use em dashes

Do not use the em dash character (`—`, U+2014) anywhere: not in code, comments,
docstrings, documentation, commit messages, or any text you output. This applies
without exception.

Instead, use whichever of these reads best:
- a comma
- a colon
- parentheses
- " - " (a hyphen with a space on each side)

This rule also covers the en dash (`–`, U+2013) when it is being used as a
sentence break. Ordinary hyphens in compound words (for example "cross-venue")
are fine.
